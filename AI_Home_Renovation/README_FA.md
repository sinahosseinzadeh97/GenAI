## 🚀 راه‌اندازی سریع

### نیازمندی‌ها
- Python 3.10+
- کلید API گوگل

### نصب

```bash
# 1. نصب کتابخانه‌ها
pip install -r requirements.txt

# 2. تنظیم کلید API
# فایل .env را ویرایش کنید
```

## 🤖 ربات تلگرام

### راه‌اندازی در 3 مرحله:

**1. دریافت توکن از BotFather@**
```
1. به @BotFather پیام دهید
2. /newbot را بفرستید
3. توکن را کپی کنید
```

**2. اضافه کردن به .env**
```bash
TELEGRAM_BOT_TOKEN=توکن_شما
```

**3. اجرا**
```bash
python3 telegram_bot.py
```

## 💬 استفاده

ربات شما دو زبانه است! دستورات:
